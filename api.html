Exclusion screening API

api.rosterproof.com · one key, three endpoints · weekly snapshot of every list

Screen an NPI, a person or an organization against the OIG LEIE, SAM.gov, the FDA debarment and investigator-disqualification lists and 38 state Medicaid exclusion lists in one call. Same published data as the Snowflake listing and the download files, loaded weekly. Free plan: 2,000 lookups a day, 500 queries per request. Machine-readable spec: openapi.json.

1. Get a key

curl -s https://api.rosterproof.com/v1/keys \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@organization.com","org":"Example Health"}'
# -> {"api_key":"rp_live_…","plan":"free","daily_lookups":2000}   (shown once)

Or get one here.

3. Screen a batch

curl -s https://api.rosterproof.com/v1/screen -H 'Authorization: Bearer rp_live_…' \
  -H 'Content-Type: application/json' \
  -d '{"npis":["1891616215","1234567893"],
       "names":[{"last":"Smith","first":"John","state":"CA"}],
       "organizations":[{"name":"Quality Poultry and Seafood Inc."}]}'
# -> {"as_of":"…","lookups":4,"hits":2,"results":[{"query":{"npi":"1891616215"},"match_method":"NPI (NPPES-verified)","matches":[…]}, …]}

NPI queries are exact against NPPES-verified matches (and source-printed NPIs). Name queries are exact on the normalized name (accents and suffix tokens like Jr., MD ignored) with optional state; they can return namesakes — read tier, npi_origin and needs_human_review before acting. Organization queries match the normalized business name.

4. Poll for changes

curl -s 'https://api.rosterproof.com/v1/changes?since=2026-10-01&limit=1000' -H 'Authorization: Bearer rp_live_…'
# -> {"count":1000,"next_cursor":123456,"changes":[{"change_type":"ADDED","observed_at":"…","record":{…}}, …]}
# page with &cursor=<next_cursor> until next_cursor is null

Limits, status, terms

GET /v1/status (no key) returns the snapshot date and counts. Rate-limit headers (X-RateLimit-Used / -Limit, per day) come back on every authenticated call; the free plan is 2,000 lookups a day and 500 queries per request — email support@rosterproof.com for more. Every response carries the notice: verify any hit against the source agency (and OIG's SSN-based search for LEIE) before adverse action, and the attribution pointer; NC and TX records are included under non-commercial permissions (see the use label). RosterProof is the exclusion and owner-screening layer that feeds compliance, payment-integrity, and fraud programs — not a fraud detector.
